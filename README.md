How to run the project


Clear setup and execution instructions

Run py app.py, then navigate to your localhost server in a browser (I’ve only tested this on chrome, so probably use that)
In the username tab, type “tim_prof” and in the password input, type “password”
Add courses like “MATA22” or “CSCA67”, full database allowed inputs will be seen below. This is not sensitive to capitals.
Click on a course, and click on the 2nd tab at the top.
Create new nodes, and adjust the weighting as needed. There is no automatic adjusting, if you input mathematically incorrect/inaccurate data it will not work as intended. You must match the names of the nodes to your imported crowdmark evaluation tabs, and max points will be the “100%” margin
Navigate to the third tab, and see the changed grades according to your new schema
Click the logout button in the bottom right when done
